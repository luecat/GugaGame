# GugaGame

一款使用純 HTML、CSS 與 JavaScript 製作的企鵝桌寵遊戲。

## 目前功能

- 企鵝隨機散步
- 單點跳躍、連點轉圈
- 拖動企鵝、重力加速落下與高處摔傷
- 跳躍與墜落時的落地音效
- 血量、飽食度與好感度
- 摔落高度會提高傷害，並按傷害量降低好感度
- 血量歸零時會觸發 jumpscare 與死亡畫面
- 餵食互動
- 依瀏覽器時間切換晝夜
